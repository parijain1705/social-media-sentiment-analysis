🛠️ 6-Step Machine Learning Pipeline

Reproducible offline workflow built with Scikit-Learn and NumPy.

1

Data Synthesis

1,800 balanced tweets generated with templates, handles, links, and 18% label noise.

2

Text Cleaning

Removes URLs, mentions, digits, and punctuation while preserving hashtag content.

3

TF-IDF Vectorization

Extracts unigram & bigram features with min_df = 2, yielding 566 vocabulary terms.

4

Model Training

Fits Logistic Regression, Multinomial Naive Bayes, and Linear SVM on a 75% stratified split.

5

Evaluation

Assesses 5-fold CV score, precision, recall, F1, and calculates confusion matrices.

6

Inference

Real-time classification of unseen user posts with probability confidence scores.
